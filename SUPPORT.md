# Support Policy & Compatibility Matrix

## Compatibility Matrix

NexPHP is tested and maintained across the following environments:

| Component | Supported Version | Notes |
| :--- | :--- | :--- |
| **PHP Runtime** | PHP 8.3, 8.4, 8.5+ | Strict typing, Fiber support, Enums, Attributes |
| **Runtimes** | Classic PHP-FPM, Persistent Workers, FrankenPHP | Dual-runtime readiness |
| **Databases** | SQLite 3.35+, MySQL 8.0+, PostgreSQL 14+ | Standard PDO driver |
| **Web Servers** | Caddy, FrankenPHP, Nginx, Apache | Reverse proxy or native worker |
| **Composer** | 2.2+ | PSR-4 autoloading |
